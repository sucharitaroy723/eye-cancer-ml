Interpretation note

F1 scores in the 0.31–0.36 range are expected for this dataset. With three near-equal classes (~33% each), the random baseline is 0.333. The available features — demographics, treatment type, laterality — do not have strong causal relationships with clinical outcome. The pipeline's value lies in its methodological rigor, not the absolute metric. Real-world performance would require richer molecular and longitudinal features (tumor histology, BRAF status, longitudinal imaging).
